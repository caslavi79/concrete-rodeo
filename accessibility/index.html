Accessibility Statement

Effective date: June 30, 2026

Concrete Rodeo wants concreterodeobcs.com to be usable by as many guests as possible, including visitors using screen readers, keyboard navigation, zoom, captions, or other assistive technology.

Our accessibility goal

We work toward WCAG 2.1 Level AA as a practical target for readable text, keyboard access, visible focus states, labels, alt text, and responsive layouts.

Need assistance?

If any part of the Site is difficult to use, contact us at concreterodeobryan@gmail.com. Please include the page URL and what you were trying to do so we can help and improve the page.

Third-party content

Some linked services, maps, social platforms, menus, or reservation tools are controlled by third parties. If a third-party tool creates a barrier, contact us and we will provide a reasonable alternate path.
